# Source PDF availability and handoff note

The current `sadie1` GitHub repository contains no original book PDFs or research-article PDF files. In `references/originals/` and `references/working/`, only placeholder files are present. The accessible project source set includes book-chapter evidence summaries/audits, research bibliography and verification reports, and the evidence pipeline workbook.

This folder therefore contains:
- Book and chapter citations with publisher access links.
- A 14-paper bibliography with DOI, PMID and PMCID links where recorded.
- Project audit statuses for full-text versus abstract-only access.
- Links to project-created evidence summaries and audits.

It does **not** contain downloadable copies of the 2 books or 14 papers. We should not imply that an article PDF is attached merely because a PubMed or PMC link is listed. Please add the original files only from copies you are authorized to share, or ask the surgeon/library to retrieve the papers through their institutional access.

Project audit recorded 3 papers as full-text verified (PAP-003, PAP-012, PAP-014) and 11 as abstract-only. These are the statuses in the project report; a later paper-by-paper evidence audit is still needed before using any abstract-only item for detailed methods, numerical cutoffs or claims.
