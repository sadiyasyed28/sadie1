# ADRAB — Surgeon Source Pack

Prepared from the accessible source inventory and reports in the `sadie1` repository.

## Purpose
This folder is a source handoff for surgeon review. It contains bibliographic references and links to project-created chapter evidence summaries/audit reports. The original book PDFs and 14 article PDFs are **not present in the current GitHub repository**, so they have not been copied into this folder. Use the publisher/PubMed/PMC links below to access the publications through authorized institutional or publisher access. Do not treat this index as a substitute for reading the source articles.

## Book source scope
The project audit for Fonseca Chapter 12 explicitly says its extracted records are diagnostic/radiographic injury-assessment material and do not themselves establish postoperative treatment-outcome success criteria. Perry's “Aftercare and Follow-up” chapter is the more directly postoperative source. See the linked chapter audit files before using either source to justify a rubric criterion.

## Important evidence-status note
The project's verification audit classifies **3** papers as full-text verified and **11** as abstract-only. These statuses are reported from the project audit, not independently re-audited here. Abstract-only sources must not be used to justify detailed thresholds or full-text claims.

## For surgeon review
Please review the source publications and tell the project team which postoperative factors, measurement methods, follow-up times and interpretations are clinically appropriate. This source pack does not propose approved cutoffs, weights or a validated combined healing score.

## Citation corrections / cautions
The repository contains inconsistencies between older summary files and the later detailed verification audit. In particular, the research audit should be treated as the bibliographic index to reconcile against publisher records before citing any paper formally. The Springer table of contents lists “Aftercare and Follow-up” as item 20, while its chapter DOI URL ends in `_19`. Preserve both details when tracing the source.
