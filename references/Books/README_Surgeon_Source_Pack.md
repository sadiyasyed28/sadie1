# ADRAB — Surgeon Source Pack

Prepared from the accessible source inventory and reports in the `sadie1` repository.

## Purpose
This folder is a source handoff for surgeon review. It contains bibliographic references and project-created chapter evidence summaries/audit reports. It does **not** contain the full copyrighted books or full-text PDFs of all 14 papers. Use the publisher/PubMed/PMC links below to access the source publications through authorized institutional or publisher access.

## Important evidence-status note
The project's verification audit classifies **3** papers as full-text verified and **11** as abstract-only. These statuses are reported from the project audit, not independently re-audited here. Abstract-only sources must not be used to justify detailed thresholds or full-text claims.

## For surgeon review
Please review the source publications and tell the project team which postoperative factors, measurement methods, follow-up times and interpretations are clinically appropriate. This source pack does not propose approved cutoffs, weights or a validated combined healing score.

## Citation corrections / cautions
The repository contains inconsistencies between older summary files and the later detailed verification audit. In particular, the research audit should be treated as the bibliographic index to reconcile against publisher records before citing any paper formally. The second book chapter number is Chapter 19, despite older filenames using “chapter_20”.
